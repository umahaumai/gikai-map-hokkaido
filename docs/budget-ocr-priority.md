# 予算OCR候補 優先順位メモ

最終更新: 2026-05-20

`site/data/budget_sources.json` の `取得候補` から、次に公開OCRへ進める自治体を選ぶためのメモ。
公開データ化する時は、`data/{slug}/budgets/` と `site/data/{slug}/budgets/` を揃え、`budget_sources.json` を `取込済み` に更新する。
規模や公開範囲が決まらないものは `保留` とし、候補一覧からは外して出典だけ残す。

## 保留

### 札幌市

- 公式ページ: [令和8年度予算](https://www.city.sapporo.jp/zaisei/kohyo/yosan-kessan/r8/reiwa8nendo_yosan.html)
- 位置づけ:
  - 予算書、説明書、企業会計、概要、局別資料などが揃っていて価値は高い。
  - ただし規模が大きく、公開用データとローカル専用データの境界を慎重に扱う必要がある。
- 再開時の判断:
  - 最初に公開する範囲を「概要・主要資料」に絞るか、会計別に段階取込するかを決める。
  - 札幌市の詳細な局別資料を公開サイト側に持つべきか、ローカルMCP専用にするかを確認する。

### 恵庭市

- 公式ページ: [令和8年度予算書](https://www.city.eniwa.hokkaido.jp/kurashi/shiseijoho/shinozaisei/yosan/22418.html)
- 既存データ: `members` / `minutes` / `themes` / `budgets` あり（完全機能3市）
- 令和8年度PDF: 予算書本体15冊（一般会計・特別会計・公営企業会計）。結合すると410ページ。
- 取込結果:
  - `pdftotext -layout` で本文が取れたのは410ページ中124ページだった。残りはA3横長の歳入歳出予算表が中心でテキスト層が無く、286ページ（69.8%）が100字未満の状態だった。
  - ページ画像のOCR（表構造を保つ指示つき）で236ページを補完。総文字数は 280,523 → 539,955字。
  - 適用スクリプト: `node site/scripts/apply-budget-ocr-text.mjs --sources site/scripts/budget-ocr-sources/eniwa-2026.json --ocr-dir <OCRのMarkdownを置いたディレクトリ>`
  - 読み取れているページ（既定100字以上）は上書きしないので、既存テキストの品質は落ちていない。同じエンジンでの再実行は冪等。
  - `data/eniwa/budgets/2026/manifest.json` の `ocr_patches` に補完した範囲・エンジン（`gemini-3.7-flash`）・ページ数を記録。
- 良い点:
  - 歳入歳出予算表の款・項・目と金額が予算書内検索で引けるようになった。
- 注意点:
  - OCRテキストは検索の入口。金額・費目名・表の行位置は原本画像で確認する。
  - 表を平文にするときは空セルを落とさない。落とすと「節 区分」だけの行が「目」列にあるように見え、どの款・項・目の金額か読み違える。
  - 決算書・財政指標はこのサイトに機能が無い（2026-09-18時点で全自治体とも未取込）ため対象外。

## 次の作業

1. 予算OCRは新しい `取得候補` を決めるまで停止する。

3. 公開データ化する場合は、`node scripts/sync-site-data.mjs --slug <slug> --build-capabilities --verify` と `node scripts/data-health.mjs --strict` を通す。
